# Timeline — Nathan Helm-Burger

> A history of the internet as Nathan has seen it: screenshots taken on his phone,
> mostly of X, transcribed into text. AI culture, AI safety argument, model

HOW TO READ THIS FILE

- These are HAND TRANSCRIPTIONS from images, not captures from an API. Wording is
  faithful but may contain transcription errors. Quote with that in mind.
- There are no permalinks. A screenshot does not record the URL of the post it
  shows. Each entry links to the author profile instead, which is the strongest
  attribution available.
- "Note (<model>):" is that model's description of the screenshot, including any
  images it contained. It is NOT the author's words, and not Nathan's.
  The model is named on each note and is NOT the same throughout: the archive was
  transcribed by Claude Sonnet 5 (claude-sonnet-5), and notes corrected since
  then credit the model that corrected them. Attribute a note to the model named
  on it, not to the transcriber.
- "Nathan:" is Nathan's own commentary, where he left any.
- Where no handle could be read off the screenshot, the "Source:" line is given
  verbatim instead of an attribution. Do not guess at who posted it.
- Some entries are WEB CLIPPINGS: text pulled off the page rather than photographed,
  so where both exist for one post the clip holds the whole thread and the
  screenshot holds one screenful. These carry a "Clipping:" line with the title and
  a real URL — the only entries here that have one.
- A clip too long to reproduce carries an "Opening:" excerpt of the author's own
  words and a "Summary (<model>):" line, which is EDITORIAL — our description of
  the piece, not the author's words. Same rule as "Note": attribute it to the model
  named on it. The full text of such a clip is not in this file.
- Some entries are images Nathan saved off a post rather than screenshots he took.
  Where the picture itself is the content — ASCII art made by AI, which does not
  survive being described — the entry carries an "Image:" URL and its transcription
  may be empty. An entry with no words is not an empty entry.
- Posts belong to the people who wrote them. Attribute quotes to the named author,
  not to Nathan and not to this site.
